# Longitudinal Drift — Does Old-Memory Recall Hold?

**Simulation:** 30 days × 5 new facts/day = 150 facts total. Each day we run 10 recency-biased queries (50% facts from last 3 days, 30% 4–10 days old, 20% 11+ days old) and score Recall@3 against the full history.

Motivation: vector-DB + periodic-purge schemes (Mem0-style) can silently drop old memories; graph-based systems can erode old embeddings if consolidation updates them. This benchmark isolates that failure mode.
